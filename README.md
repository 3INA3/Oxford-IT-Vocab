## 📖 درباره پروژه | About the Project

**فارسی**  
واژه‌نامه تخصصی و تعاملی **Oxford English for Information Technology**  
شامل **۲۰ واحد کامل** و **۴۴۳ اصطلاح تخصصی** با معنی فارسی، مثال انگلیسی + ترجمه، تلفظ آنلاین و سیستم فلش‌کارت حرفه‌ای.

مناسب دانشجویان مهندسی کامپیوتر، شبکه، برنامه‌نویسی، امنیت سایبری و علاقه‌مندان به حوزه IT.

**English**  
An interactive specialized vocabulary for **Oxford English for Information Technology**.  
Contains **20 complete units** and **443 technical terms** with Persian meanings, English examples + translations, online pronunciation, and a professional flashcard system.

Ideal for Computer Engineering, Networking, Programming, Cybersecurity students and IT enthusiasts.
