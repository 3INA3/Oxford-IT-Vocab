## 📖 درباره پروژه

واژه‌نامه تخصصی و تعاملی **Oxford English for Information Technology**  
شامل **۲۰ واحد کامل** و **۴۴۳ اصطلاح تخصصی** با معنی فارسی، مثال انگلیسی + ترجمه، تلفظ آنلاین و سیستم فلش‌کارت حرفه‌ای.

مناسب دانشجویان مهندسی کامپیوتر، شبکه، برنامه‌نویسی، امنیت سایبری و علاقه‌مندان به حوزه IT.

---

## ✨ ویژگی‌ها

| ویژگی | توضیح |
|-------|--------|
| 🃏 **فلش‌کارت حرفه‌ای** | ورق سه‌بعدی، دکمه «بلدم / هنوز یاد نگرفتم»، پیشرفت ذخیره‌شونده |
| 🔊 **تلفظ آنلاین** | تلفظ واژه و جمله مثال با Speech Synthesis |
| 🔍 **جستجوی هوشمند** | جستجو روی انگلیسی، فارسی، مثال و ترجمه |
| ⭐ **علاقه‌مندی‌ها** | ذخیره لغات مورد علاقه (localStorage) |
| 📖 **حالت مطالعه** | مخفی کردن معنی برای تمرین فعال |
| 🌙 **حالت روز / شب** | پشتیبانی کامل از Dark Mode |
| 🇮🇷 **راست‌چین کامل** | طراحی کاملاً RTL و فارسی‌محور |
| ⌨️ **میانبرهای کیبورد** | `Space` ورق • `←→` ناوبری • `S` درهم • `Esc` خروج |
| 📱 **ریسپانسیو** | سازگار با موبایل، تبلت و دسکتاپ |
